La procédure d'installation de Docker sur Debian 13 est simple et rapide. Il est recommandé d'utiliser le dépôt officiel de Docker pour obtenir la dernière version stable.

La procédure est disponible sur le site officiel de Docker : [https://docs.docker.com/engine/install/debian/](https://docs.docker.com/engine/install/debian/)
