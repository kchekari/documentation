## Ajout de l'exporter dans Prometheus
Nous allons modifier le fichier
```bash
root@MONITORING-D13:~ # nano /etc/prometheus/prometheus.yml

  - job_name: winsrv
    static_configs:
      - targets: ['192.168.130.101:9182']

root@MONITORING-D13:~ # service prometheus restart
```
