### Depuis un terminal

Lancer la commande :

```bash
ip a
```

![alt text](images/ubuntu-ip-1785847406225.png)

### Depuis l’interface graphique

Aller dans les paramètres filaire de votre carte réseau.

![alt text](images/ubuntu-ip-1785847508449.png)

On clique ensuite sur la roue

![alt text](images/ubuntu-ip-1785847541398.png)

Et les informations IP s’affiche.

![alt text](images/ubuntu-ip-1785847564552.png)
