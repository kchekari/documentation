## Installation d’Ubuntu

Démarrer la machine virtuelle, il faut choisir, essayer ou installer Ubuntu.

![alt text](images/ubuntu-installation-1785845394455.png)

Le système d’exploitation se lance
Commencer par choisir la langue :

![alt text](images/ubuntu-installation-1785845492434.png)

Passer l’écran d’accessibilité

![alt text](images/ubuntu-installation-1785845503234.png)

Puis sélectionner le clavier Français.

![alt text](images/ubuntu-installation-1785845514801.png)

Choisir la connexion Internet par câble

![alt text](images/ubuntu-installation-1785845524815.png)

Choisir d'`installer` Ubuntu plutot que de l’essayer.

![alt text](images/ubuntu-installation-1785845576341.png)

Choisir l’installation interactive

![alt text](images/ubuntu-installation-1785845625396.png)

Ne pas installer de logiciel complémentaire, Installation par défaut.

![alt text](images/ubuntu-installation-1785845660514.png)

Pas de logiciels propriétaires recommandés.

![alt text](images/ubuntu-installation-1785845672330.png)

Effacer le disque et installer Ubuntu

![alt text](images/ubuntu-installation-1785845681909.png)

Ne pas chiffrer le disque, nous sommes en test.

![alt text](images/ubuntu-installation-1785845690530.png)

Il faut ensuite créer votre compte utilisateur et nommer l’ordinateur.
Créer l’utilisateur `etudiant` avec le mot de passe `Etudiant_1234` (à taper deux fois).

![alt text](images/ubuntu-installation-1785845756209.png)

Choisir le fuseau horaire

![alt text](images/ubuntu-installation-1785845774499.png)

Et c’est parti !

![alt text](images/ubuntu-installation-1785845789368.png)

Il faut maintenant patienter

![alt text](images/ubuntu-installation-1785845800081.png)

Une fois l’installation terminée, il faut redémarrer la machine virtuelle et valider par `Entrée` quand on vous demande de supprimer le média d’installation.

![alt text](images/ubuntu-installation-1785846540070.png)

Il est maintenant possible de se connecter sur la session avec l’utilisateur que vous avez précédemment créé.

![alt text](images/ubuntu-installation-1785846661676.png)

## Configuration Post-Installation

Assistant de configuration

![alt text](images/ubuntu-installation-1785846905494.png)

Ne pas activer les services de géolocalisation

![alt text](images/ubuntu-installation-1785846947860.png)

Ne pas envoyer vos données systèmes

![alt text](images/ubuntu-installation-1785846966094.png)

Choisir le thème de votre choix, clair ou sombre.

![alt text](images/ubuntu-installation-1785846994124.png)

Terminer sans installer d’application

![alt text](images/ubuntu-installation-1785847007153.png)

Si vous avez une fenêtre de mise à jour qui se lance, choisir de les installer.
Les paquets se mettrons à jour.

L’installation est terminée.

![alt text](images/ubuntu-installation-1785847044596.png)
