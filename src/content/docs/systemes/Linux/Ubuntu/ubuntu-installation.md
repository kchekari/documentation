## Installation d’Ubuntu

Démarrer la machine virtuelle, il faut choisir, essayer ou installer Ubuntu.
![alt text](images/ubuntu-installation-1765897616694.png)
Le système d’exploitation se lance
![alt text](images/ubuntu-installation-1765897628890.png)
Ensuite, choisir la langue :
![alt text](images/ubuntu-installation-1765897635926.png)
Passer l’écran d’accessibilité
![alt text](images/ubuntu-installation-1765897642652.png)
Puis sélectionner le clavier Français.
![alt text](images/ubuntu-installation-1765897650862.png)
Choisir la connexion Internet par câble
![alt text](images/ubuntu-installation-1765897657559.png)
Le système va détecter que des mises à jour sont disponibles. Choisissez de les installer.
Une fois que le téléchargement est terminé, il faut fermer l’installateur
![alt text](images/ubuntu-installation-1765897761388.png)
Le système est disponible en version live (pour faire des tests). Si vous redémarrez, tout sera perdu.
Pour le relancer, choisir l’installation interactive
![alt text](images/ubuntu-installation-1765897727819.png)
On valide les étapes comme précédemment jusqu’au choix de l’installation interactive.
![alt text](images/ubuntu-installation-1765897692810.png)
Ne pas installer de logiciel complémentaire, Installation par défaut.
![alt text](images/ubuntu-installation-1765897818368.png)
Pas de logiciels propriétaires recommandés.
![alt text](images/ubuntu-installation-1765897831085.png)
Effacer le disque et installer Ubuntu
![alt text](images/ubuntu-installation-1765897857617.png)
Ne pas chiffrer le disque, nous sommes en test.
![alt text](images/ubuntu-installation-1765897865233.png)
Il faut ensuite créer votre compte utilisateur et nommer l’ordinateur.
Créer l’utilisateur carriat avec le mot de passe « Carriat_1234 » (à taper deux fois).
![alt text](images/ubuntu-installation-1765897875265.png)
Choisir le fuseau horaire
![alt text](images/ubuntu-installation-1765897886188.png)
Et c’est parti
![alt text](images/ubuntu-installation-1765897920511.png)
Il faut maintenant patienter
![alt text](images/ubuntu-installation-1765897929303.png)
Une fois l’installation terminée, il faut redémarrer la machine virtuelle
![alt text](images/ubuntu-installation-1765897941084.png)
Il est maintenant possible de se connecter sur la session avec l’utilisateur que vous avez précédemment créé.
![alt text](images/ubuntu-installation-1765897952485.png)
