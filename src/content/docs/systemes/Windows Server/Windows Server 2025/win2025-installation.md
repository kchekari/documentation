Démarrer sur le fichier iso et appuyer sur une touche pour lancer l’installation.

![alt text](images/win2025-installation-1766065197220.png)

Choisir la langue Français et le format de l’heure Français, suivant.

![alt text](images/win2025-installation-1766065207605.png)

Choisir ensuite le clavier Français pour un clavier AZERTY, suivant.

![alt text](images/win2025-installation-1766065231773.png)

Cocher que vous accepter de tout supprimer.

![alt text](images/win2025-installation-1766065245549.png)

Vous pouvez ensuite choisir de ne pas préciser de clé de produit.

![alt text](images/win2025-installation-1766065253235.png)

Pour avoir un bureau, il faut choisir une version avec expérience utilisateur.

![alt text](images/win2025-installation-1766065260430.png)

Il faut accepter le contrat de licence.

![alt text](images/win2025-installation-1766065269797.png)

Choisir le disque où sera installé Windows Server 2025. suivant.

![alt text](images/win2025-installation-1766065276695.png)

Puis, il reste à lancer l’installation, Installer.

![alt text](images/win2025-installation-1766065283540.png)

L’installation se lance.

![alt text](images/win2025-installation-1766065290233.png)

Après un redémarrage, l’installation se poursuit.

![alt text](images/win2025-installation-1766065297716.png)

On passe à nouveau la saisie de la clé de produit.

![alt text](images/win2025-installation-1766065305481.png)

On saisit ensuite le mot de passe du compte administrateur local.

![alt text](images/win2025-installation-1766065312962.png)

L’installation est terminée, nous pouvons ouvrir une session.

![alt text](images/win2025-installation-1766065318745.png)

Il ne reste plus qu’à configurer les données utilisateur.

![alt text](images/win2025-installation-1766065325189.png)

Choisir les possibilités les plus restrictives.

![alt text](images/win2025-installation-1766065331363.png)

Bonne utilisation !
